# Developer Tools & Utility Scripts

This folder contains Python scripts used for development purposes, database patching, and localized offline/online schema adjustments during development.

## Scripts Overview

1. **`modify_invoice.py`**
   - Utility for modifying invoice data/schema or correcting records locally.
2. **`update_invoice.py`**
   - Utility to run bulk operations or structural updates on local invoices.
3. **`update_rep_response.py`**
   - A patching utility that updates/prepares local Dart screens (`rep_response_screen.dart`) for rep response handling.

> [!NOTE]
> These scripts are for developers and should not be bundled with the production application.
