# صيدلي برو - بوابة ردود المندوبين 🌐

هذا المستودع يحتوي على صفحة الويب التي يفتحها مندوب المبيعات عند استلامه رابط النواقص من الصيدلية.

## 🔗 رابط الصفحة
```
https://mohamedelsayed1475-wq.github.io/saydali-app1/?code=XXXXXXXX
```

## ✅ المميزات
- يعمل بدون إنترنت ثابت (يكفي نت المندوب)
- لا تكلفة سيرفر على المطور
- رابط كل صيدلية مختلف فقط في الـ `code`
- واجهة عربية كاملة RTL
- يعمل على أي هاتف أو كمبيوتر

## 🚀 نشر على GitHub Pages
1. ارفع ملف `index.html` لهذا المستودع
2. اذهب لـ Settings → Pages
3. اختر Source: `main` branch وفولدر `/` (root)
4. احفظ وانتظر دقيقة - الصفحة ستكون جاهزة
