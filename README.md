# Saydali Pro - صيدلي برو

## 📌 ملخص المشروع
**صيدلي برو** هو نظام إدارة متكامل ومبتكر مصمم خصيصاً للصيدليات ليعمل كحل ذكي وفعال لإدارة الأنشطة اليومية.
- **المشكلة:** يواجه الصيادلة تحديات يومية في تتبع الأدوية الناقصة، حساب ديون العملاء بشكل دقيق، التواصل مع مناديب المبيعات للحصول على أفضل العروض، وتنظيم فواتير البيع.
- **الحل:** يوفر التطبيق بيئة رقمية متكاملة تعمل محلياً (Offline-First) وسحابياً لإدارة النواقص، ديون العملاء، فواتير المبيعات، ومزامنة طلبات المندوبين عبر روابط ويب، بالإضافة لمساعد ذكي للرد على الاستفسارات الدوائية، وإدارة دقيقة لصلاحيات المساعدين والمصروفات.
- **الجمهور المستهدف:** أصحاب الصيدليات والصيادلة في مصر والوطن العربي الذين يبحثون عن أداة حديثة وموثوقة لإدارة صيدلياتهم.

## 🚀 المميزات الرئيسية للتطبيق

*   **📦 إدارة النواقص الذكية:**
    *   إضافة النواقص وتصنيفها كـ "عاجل" أو "عادي" مع تتبع حالتها (معلق، معروض، مغطى، غير متوفر).
    *   **جديد:** اقتراحات ذكية لبدائل الأدوية من قاعدة البيانات المحلية المفلترة حسب دولة الصيدلية (مصر، السعودية، إلخ) مع دمجها وتصنيفها باستخدام خوارزميات البحث التقريبي (`FuzzySearch`).
*   **👥 إدارة المندوبين وتفاعلية الردود:**
    *   دليل المندوبين وتقييماتهم وشركاتهم.
    *   **جديد:** استيراد المندوبين مباشرة من جهات اتصال الهاتف لتسريع عملية التسجيل.
    *   إرسال طلبات النواقص بضغطة زر عبر روابط ويب وتكامل Supabase، واستقبال عروض المندوبين بأسعارهم ونسب الخصم.
    *   تحليل وقراءة نصوص رسائل المندوبين تلقائياً لاستخراج الأدوية وأسعارها وعروضها.
    *   **جديد:** إضافة الأدوية تلقائياً للنواقص في حال إفادة المندوب بعدم توفرها.
*   **💳 إدارة حسابات العملاء والديون:**
    *   ملف كامل لكل عميل يشمل رصيد المديونية الكلي، تاريخ الاستحقاق، وصورة العميل.
    *   **جديد:** استيراد العملاء مباشرة من جهات اتصال الهاتف لسهولة وسرعة الإضافة.
    *   سجل تفصيلي لحركات الديون (سحب / سداد جزء) مع إمكانية إرفاق صور الإيصالات.
*   **🧾 فواتير المبيعات ونقطة البيع (POS):**
    *   شاشة POS مدمجة تدعم إضافة الأصناف، مسح الباركود بالكاميرا، تطبيق الخصومات، وحساب المبالغ المدفوعة والمتبقية.
    *   توليد فواتير PDF احترافية لطباعتها أو مشاركتها.
*   **🔐 إدارة صلاحيات المساعدين (Assistants Control):**
    *   إضافة مساعدين للصيدلية وتحديد صلاحياتهم بدقة (إضافة ديون، تعديل مديونية، حذف بيانات، عرض التقارير، إدارة الفواتير والمندوبين والنواقص).
    *   تسجيل تفصيلي لجميع أنشطة المساعدين في سجل الأنشطة (Activity Log) لضمان الأمان والشفافية.
    *   تأمين الدخول برقم سري (PIN) مخصص لكل مستخدم.
*   **📊 التقارير المالية والإحصائيات:**
    *   لوحة تحكم (Dashboard) ذكية تعرض ملخصاً بيانياً للنواقص وإجمالي الديون والمصروفات.
    *   رسوم بيانية توضح المبيعات الأسبوعية/الشهرية وتتبع نمو الصيدلية.
*   **⏳ إدارة تواريخ انتهاء صلاحية الأدوية:**
    *   تسجيل كميات الأدوية وتاريخ انتهاء صلاحيتها مع اسم المورد لعرض تنبيهات وقوائم بالأدوية القريبة من الانتهاء.
*   **💸 إدارة المصروفات (Expenses):**
    *   تسجيل المصروفات اليومية للصيدلية وتصنيفها لمتابعة التدفق المالي بدقة.
*   **☁️ مزامنة سحابية وجدولة البيانات:**
    *   دعم كامل للعمل دون اتصال بالإنترنت مع جدولة ومزامنة البيانات تلقائياً مع Supabase.

## 🛠️ التقنيات المستخدمة
تم بناء التطبيق باستخدام إطار عمل **Flutter** مع لغة **Dart**، بالاعتماد على المكاتب والحزم الأساسية التالية:

- **قاعدة البيانات والتخزين:** `sqflite` (للتخزين المحلي)، `path`.
- **إدارة الحالة:** `provider`.
- **الخدمات السحابية:** `http` (للاتصال بـ Supabase والمزامنة).
- **جهات الاتصال والتكامل:** `flutter_contacts` (لإضافة العملاء والمندوبين مباشرة من الهاتف).
- **الذكاء الاصطناعي:** `google_generative_ai` و `google_mlkit_text_recognition`.
- **الواجهة والرسوميات:** `flutter_slidable`, `fl_chart`, `google_fonts`.
- **الملفات والطباعة:** `pdf`, `printing`, `excel`, `file_picker`, `syncfusion_flutter_pdf`.
- **أدوات النظام والأمان:** `mobile_scanner`, `qr_flutter` (للباركود)، `flutter_local_notifications`, `share_plus`, `crypto` (تشفير وقفل).

## 🗄️ مخطط قاعدة البيانات المحلية (SQLite Database Schema)

يحتوي التطبيق على الهيكل البرمجي التالي لقاعدة البيانات المحلية `saydali_pro.db`:

1.  **جدول النواقص (`shortages`)**
    *   تخزين الأدوية المطلوبة للطلب.
    *   الحقول: `id`, `name`, `company`, `quantity`, `status` (pending, offered, covered, stubborn), `is_urgent`, `notes`, `cloud_id`, `is_synced`, `created_by`, `created_at`, `updated_at`
2.  **جدول المندوبين (`representatives`)**
    *   دليل مناديب شركات الأدوية.
    *   الحقول: `id`, `name`, `company`, `phone`, `rating`, `total_covered`, `notes`, `created_at`
3.  **جدول ردود المندوبين (`rep_responses`)**
    *   تخزين عروض الأسعار والخصومات المستلمة لكل ناقص من كل مندوب.
    *   الحقول: `id`, `rep_id`, `shortage_id`, `price`, `discount`, `available`, `notes`, `responded_at`
4.  **جدول العملاء (`customers`)**
    *   بيانات العملاء الذين لديهم حسابات آجلة.
    *   الحقول: `id`, `name`, `phone`, `address`, `total_debt`, `due_date`, `cloud_id`, `photo_url`, `is_synced`, `created_by`, `created_at`
5.  **جدول معاملات الديون (`debt_transactions`)**
    *   تتبع تفصيلي لكل حركة سحب أو سداد للديون.
    *   الحقول: `id`, `customer_id`, `amount`, `type` (debt, payment), `description`, `cloud_id`, `receipt_url`, `is_synced`, `created_by`, `transaction_date`
6.  **جدول الفواتير (`invoices`)**
    *   سجل فواتير المبيعات الصادرة من الكاشير.
    *   الحقول: `id`, `customer_id`, `customer_name`, `items` (نص JSON للأصناف المباعة)، `subtotal`, `discount`, `total`, `paid_amount`, `remaining`, `notes`, `cloud_id`, `is_synced`, `created_by`, `created_at`
7.  **جدول طلبات المندوبين (`rep_orders`)**
    *   طلبات الشراء المؤكدة التي تم إرسالها للمندوب.
    *   الحقول: `id`, `rep_name`, `items`, `total`, `is_paid`, `created_at`
8.  **جدول مرتجعات المندوبين (`rep_returns`)**
    *   تتبع الأدوية المرتجعة للشركات والمندوبين.
    *   الحقول: `id`, `rep_name`, `item_name`, `reason`, `reminder_time`, `is_returned`, `created_at`
9.  **جدول أكواد الاشتراك (`subscription_codes`)**
    *   الأكواد المستخدمة لتفعيل الميزات أو تمديد الاشتراكات.
    *   الحقول: `id`, `code`, `plan`, `duration_days`, `discount_percent`, `max_uses`, `used_count`, `device_id`, `is_active`, `expires_at`, `created_at`
10. **جدول الإعلانات (`ads`)**
    *   عرض العروض الترويجية والإشعارات الإدارية.
    *   الحقول: `id`, `title`, `body`, `image_url`, `link`, `button_text`, `is_active`, `screen`, `skip_duration`, `expires_at`, `target_country`, `created_at`
11. **جدول المساعدين (`assistants`)**
    *   بيانات موظفي الصيدلية وصلاحياتهم الفردية.
    *   الحقول: `id`, `name`, `phone`, `pin`, `role`, `can_add_debt`, `can_edit_debt`, `can_delete`, `can_view_reports`, `can_manage_invoices`, `can_manage_shortages`, `can_manage_reps`, `is_active`, `subscription_expiry`, `subscription_duration_days`, `created_at`
12. **جدول سجل الأنشطة (`activity_log`)**
    *   سجل رقابي لكافة الحركات التي ينفذها المساعدون.
    *   الحقول: `id`, `assistant_id`, `assistant_name`, `action`, `details`, `screen`, `created_at`
13. **جدول تواريخ انتهاء الصلاحية (`medication_expiries`)**
    *   متابعة الأدوية القريبة من تاريخ انتهاء الصلاحية.
    *   الحقول: `id`, `name`, `quantity`, `expiry_date`, `supplier_name`, `notes`, `cloud_id`, `is_synced`, `created_by`, `created_at`
14. **جدول المصروفات (`expenses`)**
    *   تسجيل المصاريف التشغيلية للصيدلية.
    *   الحقول: `id`, `category`, `amount`, `description`, `expense_date`, `created_by`, `created_at`
15. **جدول البدائل (`alternatives`)**
    *   جدول البدائل الدوائية المحلي المقترح حسب الدولة.
    *   الحقول: `id`, `medication_name`, `alternative_name`, `active_ingredient`, `country_code` (الافتراضي 'EG')، `created_at`
16. **جدول الإعدادات (`settings`)**
    *   حفظ بيانات إعدادات النظام كـ Key-Value.
    *   الحقول: `key`, `value`
