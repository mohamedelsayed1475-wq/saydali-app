# Saydali Pro - صيدلي برو

## 📌 ملخص المشروع
**صيدلي برو** هو نظام إدارة متكامل ومبتكر مصمم خصيصاً للصيدليات.
- **المشكلة:** يواجه الصيادلة تحديات يومية في تتبع الأدوية الناقصة، حساب ديون العملاء بشكل دقيق، التواصل مع مناديب المبيعات للحصول على أفضل العروض، وتنظيم فواتير البيع.
- **الحل:** يوفر التطبيق بيئة رقمية متكاملة تعمل محلياً وسحابياً لإدارة النواقص، ديون العملاء، فواتير المبيعات، ومزامنة طلبات المندوبين عبر روابط ويب، بالإضافة لمساعد ذكي (حكيم) للرد على الاستفسارات الدوائية.
- **الجمهور المستهدف:** أصحاب الصيدليات والصيادلة في مصر والوطن العربي الذين يبحثون عن أداة حديثة وموثوقة لإدارة صيدلياتهم.

## 🛠️ التقنيات المستخدمة
تم بناء التطبيق باستخدام إطار عمل **Flutter** مع لغة **Dart**. بالاعتماد على الحزم التالية في \`pubspec.yaml\`:

- **قاعدة البيانات:** \`sqflite\` (للتخزين المحلي)، \`path\`.
- **إدارة الحالة:** \`provider\`.
- **الخدمات السحابية:** \`http\` (للاتصال بـ Supabase).
- **الذكاء الاصطناعي:** \`google_generative_ai\` و \`google_mlkit_text_recognition\`.
- **الواجهة والرسوميات:** \`flutter_slidable\`, \`fl_chart\`, \`google_fonts\`.
- **الملفات والطباعة:** \`pdf\`, \`printing\`, \`excel\`, \`file_picker\`, \`syncfusion_flutter_pdf\`.
- **أدوات النظام:** \`mobile_scanner\`, \`qr_flutter\` (للباركود)، \`flutter_local_notifications\`, \`share_plus\`, \`crypto\` (تشفير وقفل).

## 🗄️ مخطط قاعدة البيانات (SQLite)

1. **جدول النواقص (\`shortages\`)**
   - الحقول: \`id\`, \`name\`, \`company\`, \`quantity\`, \`status\` (pending, offered, covered, stubborn), \`is_urgent\`, \`notes\`, \`created_at\`, \`updated_at\`
2. **جدول المندوبين (\`representatives\`)**
   - الحقول: \`id\`, \`name\`, \`company\`, \`phone\`, \`rating\`, \`total_covered\`, \`notes\`, \`created_at\`
3. **جدول ردود المندوبين (\`rep_responses\`)**
   - الحقول: \`id\`, \`rep_id\`, \`shortage_id\`, \`price\`, \`discount\`, \`available\`, \`notes\`, \`responded_at\`
4. **جدول العملاء (\`customers\`)**
   - الحقول: \`id\`, \`name\`, \`phone\`, \`address\`, \`total_debt\`, \`due_date\`, \`created_at\`
5. **جدول حركات الديون (\`debt_transactions\`)**
   - الحقول: \`id\`, \`customer_id\`, \`amount\`, \`type\` (debt, payment), \`description\`, \`transaction_date\`
6. **جدول الفواتير (\`invoices\`)**
   - الحقول: \`id\`, \`customer_id\`, \`customer_name\`, \`items\`, \`subtotal\`, \`discount\`, \`total\`, \`notes\`, \`created_at\`
7. **جداول النظام والإعدادات:** \`settings\`, \`subscription_codes\`, \`ads\`.

## 🌐 مسارات الـ API ووظيفتها (عبر Supabase)

- \`POST /rep_sessions\`: فتح جلسة سحابية جديدة عندما يرسل الصيدلي طلب نواقص لمندوب.
- \`POST /session_items\`: رفع قائمة الأدوية الناقصة لربطها بجلسة المندوب المفتوحة.
- \`GET /response_codes\`: قراءة الكود الذي يرسله المندوب للصيدلي (بعد أن يكمل المندوب تسعير الأدوية عبر الويب).
- \`GET /rep_sessions & /session_items\`: استرجاع بيانات الجلسة وتسعيرات المندوب لعرضها في التطبيق.
- \`DELETE /session_items, /response_codes, /rep_sessions\`: حذف بيانات الجلسة بالكامل من السحابة بعد استقبالها لحماية الخصوصية وتقليل التكلفة.
- \`GET /subscription_codes\`: التحقق من صحة كود التفعيل أو الاشتراك الخاص بالمستخدم.

## 📱 وصف شاشات واجهة المستخدم

- **Dashboard (الرئيسية):** لوحة تحكم تعرض ملخص النواقص، إجمالي الديون، واختصارات للوصول السريع للمهام اليومية.
- **Shortages (النواقص):** إدارة الأدوية المطلوبة مع إمكانية تعليمها كـ "عاجل"، وتتبع حالتها (مغطى، بانتظار، إلخ).
- **Reps (المندوبين):** دليل المندوبين وشركاتهم مع نظام تقييم لأداء كل مندوب.
- **Debts (الديون):** حسابات الآجل للعملاء، إضافة مديونية جديدة أو سداد جزء من الدين مع حساب تلقائي للرصيد.
- **Invoices (الفواتير):** شاشة نقطة بيع (POS) مصغرة لإضافة أصناف، مسح الباركود، تطبيق الخصومات، وطباعة الفاتورة PDF.
- **Chat/Hakim AI (حكيم):** مساعد ذكي مخصص للصيادلة للبحث عن بدائل الأدوية، التفاعلات الدوائية، وإعطاء نصائح.
- **Documents (المستندات):** حفظ وتصنيف صور التراخيص والمستندات الهامة الخاصة بالصيدلية.
- **Reports (التقارير):** إحصائيات ورسوم بيانية أسبوعية/شهرية لأداء المبيعات، سداد الديون، وتغطية النواقص.
- **Settings (الإعدادات):** التحكم في بيانات الصيدلية، تخصيص الألوان، العملة، قفل الأمان (PIN)، وإدارة النسخ الاحتياطي.
- **Send/Response Rep (مراسلة المندوب):** شاشات إنشاء رابط طلب نواقص، إرساله للمندوب على واتساب، واستلام الرد الآلي.
